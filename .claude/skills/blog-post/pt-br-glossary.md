# PT-BR register and glossary

Decisions the author has made. Add a row whenever they decide a new term.

## Register

Casual first person, like a Brazilian dev's blog: "tem" rather than "existe/há", "pra mim" is
fine, but write "para" in general. No textbook formality ("de bom grado", "Concluindo",
"Naturalmente"). Active voice: "eu faço o deploy da aplicação", not "a aplicação é deployada".
