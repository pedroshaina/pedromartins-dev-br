# pedromartins-dev-br

## Specs and plans are private

`.internal/` is a clone of the private repo `pedroshaina/internal-docs`, ignored by this repo. Full
specs go in `.internal/pedromartins-dev-br/specs/` and implementation plans in
`.internal/pedromartins-dev-br/plans/`, and they are read from there. Commit and push them in that
repo, never in this one. This overrides the superpowers default of `docs/superpowers/`.

Never copy, link or quote `.internal/` content into commits, PRs or files in this repo.
